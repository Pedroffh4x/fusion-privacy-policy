# Fusion Bot - Política de Privacidade

Este repositório contém a política de privacidade do bot Fusion para Discord.

## Como hospedar no Vercel

1. Crie um novo repositório no GitHub (ex: usion-privacy-policy)
2. Faça push deste projeto:
   `ash
   git remote add origin https://github.com/SEU_USUARIO/fusion-privacy-policy.git
   git branch -M main
   git push -u origin main
   `
3. Acesse [vercel.com](https://vercel.com) e importe o repositório do GitHub
4. O deploy será automático — copie a URL gerada (ex: https://fusion-privacy-policy.vercel.app)
5. Cole essa URL no formulário de intenções privilegiadas do Discord

## Estrutura

- `index.html` — Página da política de privacidade
- `vercel.json` — Configuração de rotas do Vercel
